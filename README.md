# MyTask-OS

Obsidian 单页任务管理工作台 · 曜石暗色主题 · 拖拽看板。

打开 `工作台.md` 即用：顶部月历 + 速记条，上方 2×2 四区（今日 / 临时 / 近期 / 长期），
底部「未安排 | 已完成」折叠区。任务为纯文本复选框行，存于 `内部/01 Tasks/` 六个
Markdown 文件，可随时手编。

## 特性

- **零构建、零配置**：整个系统就是一个 Obsidian Vault 文件夹，拷入已有 Vault 任意位置即可（自动定位），唯一依赖 [Dataview](https://github.com/blacksmithgu/obsidian-dataview)（需开启 JavaScript 查询）
- **六分区写死**：今日 / 临时 / 近期 / 长期 / 未安排（someday 想法）/ 已完成
- **完整拖拽**：行上 1/3 前插、下 1/3 后插、中间嵌为子任务；拖入已完成 = 立即完成；拖出 = 复活
- **子任务**：一级嵌套、独立勾选、n/m 进度签
- **隔夜归档**：勾选当天原地变灰，次日打开自动扫入「已完成」
- **背景三档**：玻璃卡 / 实卡 / 关，月历旁一键切换，自动记忆
- **数据即文件**：任务就是 `- [ ] 文字`，无任何元数据锁定

## 快速开始

1. 安装 [Obsidian](https://obsidian.md/)，「打开文件夹作为仓库」选中本文件夹；
   或将本文件夹整体拷入已有 Vault。
2. 启用 Dataview 插件并开启「JavaScript 查询」。
3. 打开 `工作台.md`，详见 `内部/开始使用.md`。
