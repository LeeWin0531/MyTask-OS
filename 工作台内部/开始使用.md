# 开始使用

MyTask-OS 是一个**单页任务管理工作台**：整个系统只有一页（`工作台工作台内部/工作台`），你在上面记任务、拖任务、完成任务；所有数据都存成普通的 Markdown 文件，永远属于你自己。

---

## 第一次打开

1. 安装 [Obsidian](https://obsidian.md)（桌面版）。
2. 打开 Obsidian → 「打开本地仓库（文件夹作为仓库）」→ 选中本文件夹 `MyTask-OS`。
3. 首次打开会询问是否信任此仓库：选择**信任并启用插件**。
4. 本仓库已内置唯一依赖的插件 **Dataview**，并已预置开启「JavaScript 查询」。如果页面空白或提示插件未启用，请到 设置 → 第三方插件 里启用 **Dataview**；再到 设置 → Dataview 里确认 **Enable JavaScript Queries（启用 JavaScript 查询）**已打开。
5. 打开 `工作台工作台内部/工作台`，看到问候语、月历和分区卡片，即安装完成。

## 认识工作台

页面从上到下分四块：

| 区块 | 说明 |
| --- | --- |
| **页头** | 按时段变化的问候语（夜深了 / 早上好 / 下午好 / 晚上好）+ 今天日期；右侧是**月历卡**——纯展示，不含任务数据，「今天」高亮，点 `‹ ›` 可翻看其他月份 |
| **速记条** | 输入框写「想到什么先丢进来…（Enter 记为未安排）」，按 **Enter**（或点「速记」按钮）立刻记入「未安排」分区 |
| **上方 2×2 四张卡** | 今日任务、临时任务、近期任务、长期任务，四张分区卡常驻展开 |
| **底部折叠区** | 「未安排 | 已完成」两条折叠标题条，点标题展开 / 收起，条上有任务计数 |

## 六个分区是什么

分区固定六个，含义如下：

| 分区 | 放什么 |
| --- | --- |
| **今日任务** | 今天要做的事 |
| **临时任务** | 突然被附加的、计划外插进来的事 |
| **近期任务** | 未来几天内计划要做的事 |
| **长期任务** | 远期规划，暂不排期 |
| **未安排** | 曾经冒出的、想实现的想法，先记下来，不确定什么时候开始（someday/maybe） |
| **已完成** | 归档区。不能新建任务，任务只进不出（拖出可复活），永不自动清理 |

任务**不会自动流动**：改变分区唯一的方式是手动拖拽，日期不参与任何调度。

## 日常操作

### 新增任务
点分区卡底部的「**＋ 新增任务**」按钮，出现输入框：**Enter** 确认（追加到该分区末尾），**Esc** 取消。已完成区没有新增按钮。

### 勾选完成
点任务前的复选框：任务**原地变灰划线**，行尾自动标注 `✅ 当天日期`；取消勾选则去掉标注。子任务有自己独立的复选框，勾选父任务不会自动勾选子任务。父任务有未全勾的子任务时，行上会显示 **n/m** 进度提示。

### 加子任务
鼠标悬停在任务行上，行尾出现「**＋子任务**」；点它输入内容，Enter 确认。子任务随父任务整体移动、整体归档。

### 拖拽
任何任务行都可以按住拖动：

- 拖到目标任务的**上约三分之一** → 插到它**前面**；
- 拖到**下约三分之一** → 插到它**后面**；
- 拖到**中间** → 变成它的**子任务**；
- 拖到**分区标题、折叠条或卡片空白处** → 移入该分区（「已完成」插到顶部，其余分区追加到末尾）；
- 拖**入「已完成」** → 未勾选的任务立即视为今天完成（自动打勾并标注 ✅）；
- 拖**出「已完成」** → 复活：去掉 ✅ 重新变回未完成任务；
- 拖动带子任务的任务时，整棵子树一起走。

### 隔夜归档
勾选的任务**当天原地保留**（打勾变灰）；**第二天打开工作台时**会自动扫入「已完成」区顶部，并弹出提示告知扫入条数。你什么都不用做。

## 背景显示

页头月历卡上有一个小按钮，点击在三种背景形态间循环：

**玻璃卡**（默认，卡片半透明磨砂、背景图透出）→ **实卡**（卡片不透明）→ **关**（隐藏背景图）。

你的选择会被记住，下次打开保持不变。

## 数据在哪里

`工作台工作台内部/01 Tasks/` 下的六个 Markdown 文件就是**全部数据**，每个文件对应一个分区：

```
工作台工作台内部/01 Tasks/
├── 今日任务.md
├── 临时任务.md
├── 近期任务.md
├── 长期任务.md
├── 未安排.md
└── 已完成.md
```

你可以直接在 Obsidian 里打开手编，**下次打开工作台即生效**。示例行格式：

```markdown
- [ ] 这是一个任务
- [x] 这是已完成任务 ✅ 2026-09-01
    - [ ] 这是子任务（缩进 4 个空格）
```

只认复选框行，其他内容（空行、标题、普通文字）会被忽略，随便写不会弄坏系统。更详细的手编规则见《如何修改》。

## 常见问题

- **怎么没有示例数据？** 初始就是空的，没有预置示例——打开直接用即可。若你改动过数据想找回初始状态，用文件恢复（设置 → 文件恢复）或你自己的备份。
- **怎么删除任务？** 鼠标悬停在任务行上，点击行尾出现的 **×** 即可删除（子任务行同样有 ×，只删该子任务）。删除不可恢复，注意误删；若任务还在，也可以直接拖到「已完成」归档而不是删除。
- **怎么改任务名称？** **双击**任务（或子任务）的文字即可进入行内编辑：Enter 或点击别处确认保存，Esc 撤销；清空文字确认则视为取消，不会把任务改没。
- **怎么给任务设截止日期？** 悬停任务行，点击行尾的 **📅+**，选好日期即保存；行内会出现 `📅 MM-DD` 芯片，**点击芯片可清除**截止日期。手编直接在行内写 `📅 2026-09-10`（可放在文字任意位置）。有截止的任务会以角标点显示在月历上，并在日历下方「⚠ 截止任务」列出（过期的标红）。
- **日历上的备注/纪念日怎么加？** **双击月历上的日期格**，在日历下方出现的输入框里输入文字，Enter 保存。备注显示在日历下方「📌 备注」节（悬停可点 × 删除），存放在 `工作台工作台内部/01 Tasks/日历备注.md`，也可手编。
- **手滑拖错了？** 大多数操作可逆：拖回去就行；误拖入「已完成」就拖出来（自动复活）。
- **关掉 Obsidian 丢数据吗？** 不会。每次勾选、拖拽、速记都会立即写入 `工作台工作台内部/01 Tasks/` 的文件。
- **想改外观、背景图或行为？** 见《如何修改》。


## 放进你的主 Vault（推荐）

本项目文件夹可以整体拷贝/移动进你已有的 Vault，作为子文件夹使用：

1. 把整个项目文件夹（含 `工作台工作台内部/` 和 `工作台.md`）复制进主 Vault 任意位置；
2. 打开主 Vault，点击 `工作台.md` 即可使用——无需任何配置；
3. 文件夹可以改名、可以放多层深处，系统启动时自动定位自己的位置。

数据随项目文件夹走：任务存放在项目文件夹内 `工作台工作台内部/01 Tasks/` 六个文件里。
